# 홍명보 탈출

> 대표팀 숙소 · 새벽 2시 · 소등 이후

흑백 대표팀 숙소에서 라커 열쇠 4개와 정문 비밀번호를 찾아 탈출하는 1인칭 3D 공포 게임입니다.
숙소를 순찰하는 **홍명보 감독**에게 들키지 않고 빠져나가야 합니다.

브라우저만 있으면 설치 없이 바로 플레이할 수 있습니다. 파일은 `index.html` 하나뿐입니다.

---

## 미션

| 순서 | 할 일 |
|---|---|
| 1 | 숙소 곳곳의 서랍, 사물함, 책상을 뒤져 **라커 열쇠 4개**를 찾는다 |
| 2 | 어딘가에 있는 **정문 비밀번호 메모**(4자리)를 찾는다 |
| 3 | **정문**으로 가서 비밀번호를 입력하고 탈출한다 |

- 열쇠와 비밀번호의 위치, 비밀번호 숫자는 판마다 바뀝니다.
- 서랍에서 이온음료가 나오면 스태미나가 전부 회복됩니다.
- 비밀번호를 틀리면 경보가 울리고 감독이 정문으로 달려옵니다.

## 조작법

### PC

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| 마우스 | 시점 |
| `Shift` | 달리기 (스태미나 소모, 발소리 큼) |
| `E` | 서랍 뒤지기 · 옷장 숨기/나오기 · 정문 열기 |
| `Esc` | 일시정지 |

화면을 클릭하면 마우스가 고정되고, `Esc`를 누르면 일시정지됩니다.

### 모바일

| 조작 | 동작 |
|---|---|
| 화면 왼쪽 드래그 | 이동 |
| 화면 오른쪽 드래그 | 시점 |
| `조사` 버튼 | 서랍 뒤지기 · 옷장 · 정문 |
| `달리기` 버튼 | 달리기 켜기/끄기 |

## 홍명보 감독

- 게임 시작 후 약 9초 뒤부터 숙소를 순찰합니다.
- **지나가는 곳마다 형광등이 꺼집니다.** 앞쪽 불이 꺼지면 그쪽에 감독이 있다는 뜻입니다.
- 플레이어를 발견하면 호루라기를 불고 쫓아옵니다.
- 달리는 소리, 서랍 뒤지는 소리를 듣고 찾아옵니다.
- 열쇠를 하나 찾을 때마다 조금씩 빨라집니다.
- 숨는 걸 보면 옷장 앞에서 계속 기다립니다.

### 감독이 가까이 왔다는 신호

- 발소리가 커집니다. 이어폰을 끼면 방향까지 들립니다.
- 심장 소리가 들리기 시작합니다.
- 화면 가장자리가 어두워집니다.
- 근처 형광등이 깜빡이다 꺼집니다.

---

## 생존 팁

- **불 켜진 곳은 위험합니다.** 형광등 아래에 서 있으면 멀리서도 보이고, 어두운 곳에서는 가까이 와야 보입니다.
- **달리기는 꼭 필요할 때만 씁니다.** 소리가 커서 감독을 불러들입니다.
- **옷장은 감독 시야에서 벗어난 뒤에 숨습니다.** 숨는 걸 들키면 감독이 옷장 앞에서 떠나지 않습니다.
- **가구를 방패로 씁니다.** 침대, 식당 테이블, 러닝머신 반대편으로 돌면 시간을 벌 수 있습니다.
- 상단 미니맵에 방 구조, 서랍(뒤진 곳은 어둡게 표시), 옷장, 정문 위치가 나옵니다.

## 실행 · 배포

### 바로 실행

`index.html`을 브라우저(Chrome, Edge, Safari, Firefox)로 열면 됩니다.
3D 라이브러리를 인터넷에서 불러오므로 **인터넷 연결이 필요합니다.**

### GitHub Pages

1. 저장소에 `index.html`과 `README.md`를 올립니다.
2. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`으로 접속합니다.

### Netlify

[netlify.com/drop](https://app.netlify.com/drop)에 `index.html`을 끌어다 놓으면 바로 주소가 생성됩니다.

> `index.html`에는 검색엔진 노출을 막는 `<meta name="robots" content="noindex">`가 들어 있습니다. 검색에 나오게 하려면 이 줄을 지우세요.

## 기술 정보

- 단일 HTML 파일 (약 350KB)
- 3D 렌더링: [three.js](https://threejs.org/) r128 (cdnjs)
- 효과음: Web Audio API로 실시간 생성
- 텍스처: 캔버스로 직접 생성
- 최고 기록은 브라우저 `localStorage`에 저장되며 다른 기기와 공유되지 않습니다.

## 개발자용: 디버그 메뉴

게임 중에 키보드로 `ghdaudqh`를 입력하면 디버그 메뉴가 열립니다. 한 번 더 입력하면 닫힙니다.

| 키 | 기능 |
|---|---|
| `1` | 친구 모드: 감독이 쫓아오지 않음, 스태미나 무한, 미니맵에 감독 위치 표시 |
| `2` | 비밀번호 자동 확인 |
| `3` | 라커 열쇠 4개 즉시 획득 |
